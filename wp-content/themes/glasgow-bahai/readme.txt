A custom theme for the Baha'i community of Glasgow, in the calm, spacious
visual language of bahai.org, built with original content and imagery.

== Setup after activation ==

1. Appearance > Menus: create a "Primary Menu" (assign to "Primary Menu"
   location) and a "Footer Menu" (assign to "Footer Menu" location).
2. Settings > Reading: this theme's homepage design lives in
   front-page.php and displays automatically — no static front page
   needs to be selected, though creating one for Settings > Reading is
   fine and will not conflict.
3. Create pages for: About, Devotionals, Study Circles, Junior Youth,
   Children's Classes, Get Involved, Contact — the homepage links to
   these by slug (/about/, /devotionals/, /study-circles/,
   /junior-youth/, /childrens-classes/, /get-involved/, /contact/).
4. Create a category called "events" and tag upcoming-event posts with
   it to have them appear automatically in the "What's On" section on
   the homepage.
5. Appearance > Customize > Site Identity: upload a logo (optional — a
   nine-pointed star placeholder is shown until one is set) and set the
   site title/tagline.
